## Decision

The first lab-twin milestone should be reframed from "fit or load a
Drude-Lorentz model and compare" to a stricter evidence milestone:

> Given one explicitly identified sample/stack, use calibration-only optical
> data to produce or load a physically constrained material model, freeze that
> model, predict an independent linear transmission/reflection or ellipsometry
> holdout measurement under recorded geometry, and produce a report whose claim
> status is machine-gated by provenance, split integrity, physics sanity,
> numerical reproducibility, and residual/uncertainty checks.

The next implementation slice should therefore be contract and gate plumbing,
not real data ingestion.

## Evidence Labels

Every run report must carry one claim status:

- `synthetic_software_fixture`
- `literature_reproduction_fixture`
- `calibration_only_no_holdout`
- `weak_within_dataset_holdout`
- `calibrated_linear_evidence`
- `failed_validation`

Only `calibrated_linear_evidence` can feed serious-core conclusions.

## Required Gates

Before a run can claim calibrated linear evidence, it must pass machine-readable
gates:

- Input integrity: file existence, SHA-256 hashes, units, monotonic axes, source
  labels, and registry snapshot hash.
- Split integrity: predeclared calibration/holdout split, no overlapping refs,
  and a leakage audit showing holdout data was not used in fitting.
- Physics sanity: passive-material sign checks, finite and bounded T/R/A,
  explicit branch/sign conventions, no silent substrate/default media, and
  stated roughness/coherence/backside assumptions.
- Numerical reproducibility: deterministic prediction table hash, dependency
  lock hash, code/git provenance, optimizer seed, and convergence status.
- Calibration quality: residual plots, bounds-hit checks, covariance or
  identifiability diagnostics, and simple baseline comparisons.
- Holdout prediction: frozen model hash before holdout evaluation, uncertainty
  weighted residuals, predeclared pass/fail criteria, and evidence-strength
  labeling.

## Contract Additions

The V1 contract must introduce typed records for:

- Raw artifacts.
- Samples.
- Stacks.
- Media.
- Measurements.
- Material models.
- Data splits.
- Calibration plans.
- Validation plans.
- Fit results.
- Validation results.
- Claim status.

The run manifest must include artifact hashes and semantic roles. Run identity
must include the resolved spec, registry snapshot, raw input hashes, split hash,
material model hash, simulator version, lockfile hash, and code provenance.

## Physics Traps To Guard Against

- ITO/AZO/CdO parameters are process-specific, not transferable constants.
- Ellipsometry is inverse and model-dependent; low residual does not prove
  unique `n,k`.
- Drude-only fits can hide missing oscillator/interband physics.
- Coherent TMM is not automatically the measured experiment for thick
  substrates, backside reflections, finite coherence, or wedged samples.
- Angle and polarization are not decorative for ENZ/TCO films.
- Roughness, graded layers, substrate mismatch, and normalization errors are
  likely residual sources before nonlinear physics.
- Sign conventions can silently invert loss/gain.
- The ENZ definition must be explicit.
