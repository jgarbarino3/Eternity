# Eternity AI Strategy Pack

This zip contains repo-ready strategic materials for the AI/hypothesis-learning direction of Eternity.

Files:

- `ETERNITY_AI_RESEARCH_BRIEF.md` — full Codex-facing strategy brief.
- `hypothesis_card_schema.yaml` — draft schema for structured hypotheses, claim levels, and mechanism taxonomy.
- `research_radar_keywords.yaml` — starter config for a paper/post scanner.
- `codex_hypothesis_harness_prompt.md` — paste-ready Codex prompt for implementing v0.
- `AGENTS_excerpt_eternity_ai.md` — optional excerpt for repo-level agent instructions.

Main idea:

> Build a system that learns from failed ultrafast-optics hypotheses and improves its ability to choose falsifying experiments under provenance, uncertainty, and artifact constraints.

Snapshot date: 2026-05-08. This is not a fixed roadmap; it should evolve with the repo, lab data, and new AI/science-agent work.
